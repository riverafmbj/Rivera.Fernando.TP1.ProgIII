# Rivera.Fernando.TP1.ProgIII
Trabajo Practico parte 1 Programacion III
SISTEMA DE AUTOMOVILES
Aplicación web desarrollada como trabajo práctico para la gestión de automóviles mediante una API REST.

El sistema permite consultar, agregar, modificar y eliminar automóviles. La aplicación cuenta con una interfaz web desarrollada con HTML, CSS y JavaScript, que se comunica con una API REST mediante solicitudes HTTP.

Tecnologias utilizadas: HTML5, CSS3, JavaScript, Fetch API
